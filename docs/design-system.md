## 1. Палитра

Три варианта акцентной пары. Все проверены на контраст (значения в таблице — контраст акцентного *текстового* цвета к фону).

| Вариант | Основной | Акцент-текст (тёмная / светлая) | Вторичный | Контраст текста к фону |
|---|---|---|---|---|
| **A. Индиго + мята** | `#6366F1` | `#A5B4FC` / `#4338CA` | мята `#2DD4BF` | 9.82:1 / 7.90:1 |
| B. Фиолетовый + янтарный | `#8B5CF6` | `#C4B5FD` / `#6D28D9` | янтарь `#F59E0B` | 10.60:1 / 3.3:1 ⚠ | 
| C. Синий + коралл | `#3B82F6` | `#93C5FD` / `#1D4ED8` | коралл `#FB7185` | 10.85:1 / 8.2:1 |

### Выбор: вариант A — индиго + мята

Обоснование для учебного приложения:

1. **Индиго `#6366F1` — «спокойное сосредоточение».** Синий `#3B82F6` (текущий) ассоциируется со ссылкой и «действием в интерфейсе» — это самый узнаваемый цвет для UI, поэтому карточка, кнопка и ссылка сливаются. Индиго на 8–10% темнее и холоднее: он читается как «бренд приложения», а не как ссылка.
2. **Мята/изумруд `#10B981` = правильный ответ.** Ядро приложения — цикл «ответил → верно/неверно». Зелёный для «верно» — конвенция, которую не нужно объяснять (Duolingo, Quizlet, Anki). Мята как *вторичный* акцент не спорит с индиго: один отвечает за бренд и CTA, второй — за семантику.
3. **Разделение ролей убирает конфликт.** Индиго = «что можно нажать», мята = «правильно», роза `#F43F5E` = «неверно/удалить». Три цвета, три роли, ни одного пересечения.
4. **Офлайн и ночной режим.** Индиго на `#070C16` даёт 9.82:1 — читается при вечернем свечении экрана на телефоне, не «светится». Мята на тёмной поверхности — 8.94:1.
5. **Доступность при дальтонизме.** Индиго и мята для дейтеранопии сближаются по тону, но не по роли: зелёный всегда сопровождается иконкой `check` и словом, индиго — только формой. Форма (круг/галочка/крест) различает состояние независимо от цвета.

Почему не B: янтарь `#F59E0B` на светлом фоне даёт 3.3:1 — не проходит AA для текста; пришлось бы затемнять до `#92400E`, и он перестаёт быть «янтарным». Почему не C: коралл и роза «неверно» совпадают, а `#3B82F6` почти неотличим от текущего акцента — то есть миграция без визуальной смены.

### 2.5 Подход к opacity

Прозрачность **не вычисляется в модулях**. Все полупрозрачные слои — именованные токены:

| Токен | Значение | Назначение |
|---|---|---|
| `--veil-hover` | `rgba(255,255,255,.06)` / `rgba(15,23,42,.04)` | фон при наведении |
| `--veil-active` | `rgba(255,255,255,.10)` / `rgba(15,23,42,.07)` | фон при нажатии |
| `--accent-soft`, `--success-soft`, `--danger-soft`, `--warning-soft` | 9–14% | подложки |
| `--opacity-disabled` | `0.45` | неактивный элемент |
| `--opacity-muted` | `0.72` | вторичный контент внутри блока |
| `--scrim` | `rgba(3,6,15,.66)` / `rgba(15,23,42,.40)` | затемнение под диалогом |

Правило: `opacity` на элементе с текстом **не используется** (гасит текст и ломает контраст). Приглушённый текст получают отдельным цветом `--text-3`. `opacity` допустим только на иконках-декорах и целых неинтерактивных блоках.

## 3. Типографика

**Семейство** — системный стек, без внешних шрифтов (приложение офлайн):

```css
--font-sans: system-ui, -apple-system, 'Segoe UI', Roboto, 'Helvetica Neue',
  Arial, 'Noto Sans', sans-serif;
--font-mono: ui-monospace, 'Cascadia Mono', 'SF Mono', Consolas, 'Liberation Mono', monospace;
```

`system-ui` даёт нативный UI-шрифт ОС; `'Segoe UI'` (Windows) и `'Noto Sans'` (Android/Linux) гарантируют полное покрытие кириллицы. Шрифт из старого `global.css` (`'Inter'`) удалён — он не подключался и всё равно рендерился системным.

**Масштаб 12 → 48** (мобильный → десктоп):

| Токен | px | Вес | Где используется |
|---|---|---|---|
| `--fs-12` | 12 | 700, uppercase, `letter-spacing .08em` | оверлей над словом, заголовки таблицы, «NEW»-метки |
| `--fs-14` | 14 | 400 / 600 | подпись поля, подсказка, бейдж счётчика, текст кнопки-вторички, лицензия |
| `--fs-16` | 16 | 400 | базовый текст, текст кнопки, текст поля, ячейка таблицы, тост |
| `--fs-18` | 18 | 400 | подзаголовок страницы, описание, транскрипция |
| `--fs-20` | 20 | 600 | заголовок карточки (набор слов), число в stat-плитке |
| `--fs-24` | 24 | 700 | заголовок секции, счётчик слов |
| `--fs-32` | 32 | 700 | заголовок страницы (десктоп) |
| `--fs-40` | 40 | 700 | учебное слово (десктоп) |
| `--fs-48` | 48 | 700 / 800 | заголовок приложения (моб. 32), код 404 |

**Веса:** 400 (текст) · 500 (ссылки, навигация) · 600 (кнопки, подписи, заголовки карточек) · 700 (заголовки, числа, бейджи) · 800 (только имя приложения и код 404 — больше нигде).

**Интерлиньяж:** `--lh-tight 1.2` (заголовки, крупные числа) · `--lh-normal 1.5` (текст) · `--lh-relaxed 1.65` (транскрипция, многострочные пояснения).

**Трекинг:** `-0.02em` для `--fs-32/40/48` (крупный текст без разрядки «плывёт»), `0` базовый, `0.02em` для подписей полей, `0.08em` для uppercase-12px.

**Правило:** текст никогда не смешивает два веса в одном блоке без смысловой разницы; межстрочный интервал не задаётся вручную в модулях — только через `--lh-*`.

## 6. Анимации

Правило: анимируется только то, что **объясняет произошедшее**. Никаких декоративных появлений, параллакса и «вау-эффектов».

| Что анимируется | Свойства | Длительность | Easing | Когда | `prefers-reduced-motion` |
|---|---|---|---|---|---|
| Наведение на кнопку/карточку | `background-color`, `border-color`, `box-shadow` | 180ms | `--ease-standard` | `:hover` | Без перехода, мгновенное состояние |
| Подъём интерактивной карточки | `transform: translateY(-2px)` + тень | 180ms | `--ease-out` | `:hover` | Отключить `transform`, оставить тень |
| Нажатие кнопки | `transform: scale(.98)` | 90ms | `--ease-emphasized` | `:active` | Отключить |
| Появление фокус-кольца | мгновенно, без transition | 0 | — | `:focus-visible` | Без изменений (кольцо обязательно) |
| Появление тоста | `opacity 0→1`, `translateY(12px)→0` | 260ms | `--ease-out` | mount | Оставить только `opacity` 100ms |
| Уход тоста | `opacity 1→0`, `translateY(0→8px)` | 180ms | `--ease-in` | dismiss | Только `opacity` |
| Появление модального шторки | `opacity`, `translateY(16px)`, `scale(.98)→1` | 260ms | `--ease-out` | mount | Только `opacity` 100ms |
| Смена страницы (роутер) | `opacity 0→1` | 160ms | `--ease-standard` | смена маршрута | Без анимации |
| Подсветка верного ответа | фон `--success-soft` → прозрачный | 320ms | `--ease-out` | ответ верный | Мгновенный фон, без мигания |
| Отметка неверного ответа | `translateX` −4px → +4px → −2px → 0 | 300ms | `--ease-standard` | ответ неверный | Отключить, показать только цвет и текст |
| Заполнение прогресс-бара | `width` | 240ms | `--ease-out` | смена прогресса | Без transition |
| Скелетон загрузки | блик `translateX(-100% → 200%)` | 1400ms | `linear`, infinite | пока грузится | Остановить, статичный фон |
| Спиннер | `rotate(0→360deg)` | 800ms | `linear`, infinite | пока грузится | Остановить вращение, оставить кольцо |
| Открытие нижней шторки (mobile) | `translateY(100%→0)` | 260ms | `--ease-out` | mount | Только `opacity` |

Что **не** анимируется: градиентный текст, тени карточек при скролле, hover на строках таблицы (только смена фона 120ms), цвет ссылок, появление списка наборов (только fade 160ms).

Глобальный выключатель уже есть в `tokens.css`:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 7. Иконки: эмодзи → inline SVG

**Решение: перейти на inline SVG.**

Обоснование:

1. **Эмодзи нельзя сделать наследуемыми.** `🎧`/`📚` рисуются системным emoji-шрифтом (Segoe UI Emoji на Windows, Noto Color Emoji на Android), цвет в них зашит. `color: var(--text-2)` на эмодзи не действует — они всегда цветные и всегда ярче текста рядом.
2. **Эмодзи ломают сетку.** Разные шрифты дают разную ширину и разный базовый линии: `🏠` шире `🧠`, оба вылезают за 44px-таргет и «прыгают» при переносе строки в мобильной навигации.
3. **Эмодзи плохо читаются скринридером.** `📚 Хранилище` озвучивается как «книги, хранилище» или «открытая книга» — лишнее слово в начале каждого пункта навигации.
4. **Эмодзи — визуальный шум в обучающем интерфейсе.** Шесть разных эмодзи в шапке создают ощущение «детский конструктор», а не «инструмент для работы с языком». Иконки нужны там, где они несут смысл (динамика, поиск, удаление), а не как украшение.
5. **Флаги `🇬🇧`/`🇷🇺` — отдельная проблема.** На Windows это буквенные эмодзи `GB`/`RU`, а не флаги: визуально это просто «GB» в квадрате. Плюс флаг ≠ язык, а это разные вещи (en-US, en-GB).

Реализация: inline SVG со `stroke="currentColor"` — иконка наследует цвет текста, толщина штриха одинаковая, размер задаётся через `--icon-*`. Библиотеку подключать не нужно: 24 иконки — это ~4 КБ разметки, а зависимость `lucide-react` ради 24 иконок хуже. Пути скопированы из **lucide v1.61.0** (`lucide-static`), лицензия ISC.

Общие параметры для всех иконок: `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`, `stroke-width="2"`, `stroke-linecap="round"`, `stroke-linejoin="round"`, `aria-hidden="true"` + `focusable="false"` (для декоративных) или `role="img"` + `<title>` (для одиночных кнопок).

| базовый | <480px | 1 колонка, поля 16px, нижняя навигация |
| `--bp-sm` | 480px | инлайн-пары (label + кнопка) в одну строку |
| `--bp-md` | 768px | навигация переезжает вниз, таблица → карточки |
| `--bp-lg` | 1024px | верхняя навигация + 2 колонки |
| `--bp-xl` | 1280px | сетка наборов до 4 колонок, контейнер 1120px |

### 8.2 Нижняя навигация вместо верхней

На `<768px` верхняя навигация скрывается, вместо неё — фиксированный таб-бар внизу:

```css
.tabbar {
  position: fixed;
  inset-inline: 0;
  bottom: 0;
  z-index: var(--z-header);
  display: flex;
  height: calc(56px + env(safe-area-inset-bottom));
  padding-bottom: env(safe-area-inset-bottom);
  background: var(--glass-bg);
  backdrop-filter: var(--glass-blur);
  border-top: 1px solid var(--border-subtle);
}
```

- **Безопасные зоны:** `padding-bottom: env(safe-area-inset-bottom)` — таб-бар не уезжает под «домашнюю черту» iPhone. Контент страницы получает `padding-bottom: calc(56px + env(safe-area-inset-bottom) + 16px)`.
- **Шапка на мобильном** (`≤767px`) содержит только бренд и переключатель темы — 56px высотой, не sticky (иначе съедает место при скролле).
- **Безопасная зона сверху** — `padding-top: env(safe-area-inset-top)` на `.header`, если используется в standalone-режиме (PWA).
- **Тап-таргеты:** каждый пункт таб-бара — минимум 56×48 (ширина делится поровну, но при 320px ширины на 5 пунктов это 64px — норма), иконка 20px + подпись 12px.

### 8.3 Как ломается сетка

| Экран | ≥1024px | 768–1023px | 480–767px | <480px |
|---|---|---|---|---|
| **Главная** | 3 кнопки-строки в колонке, max-width 600px | то же | 3 кнопки на всю ширину, h 56 | то же, поля 16px |
| **Учить** | карточка 650px, фото 160×160 | карточка 100% | фото 140×140, слово 32px, поле ввода sticky над таб-баром | слово 28px, поле и кнопка прижаты к низу |
| **Хранилище** | таблица 6 колонок, max-width 1300px | таблица, горизонтальный скролл | **таблица → карточки**: каждая строка = карточка (фото 48, EN 16/600, RU 14/400, счёт, кнопка удаления) | то же |
| **Наборы** | `repeat(auto-fill, minmax(240px, 1fr))` → 4 колонки | 3 колонки | 2 колонки (`minmax(160px, 1fr)`, gap 12) | 1 колонка |
| **Добавить** | форма max-width 700px, 1 колонка | то же | 1 колонка, поля 16px, превью 120px | то же |
| **404** | код 48px | код 48px | код 40px | код 32px |

Ключевое правило: **используй `minmax(0, 1fr)`**, иначе длинное слово («pneumonoultramicroscopicsilicovolcanoconiosis») распирает грид и ломает ширину колонки. Для таблицы в Хранилище на мобильном — не `overflow-x: auto`, а перестройка в карточки: горизонтальный скролл на телефоне неудобен и скрывает половину колонок.

### 8.4 Тач-таргеты

- Все интерактивные элементы — минимум 44×44 px (`--tap-min`).
- Иконка-кнопка: 44×44 на мобильном, 36×36 на десктопе (мелкие цели на десктопе допустимы — там есть курсор).
- Между интерактивными элементами — зазор ≥8px, чтобы промахнуться было нельзя.
- `padding` в горизонтальном списке (наборы) — не меньше 12px от края текста до границы карточки.

## 9. Доступность

### 9.1 Общие правила

1. **Фокус-кольцо** — единое: `outline: 2px solid var(--focus-ring-color); outline-offset: 2px`. Никогда не `outline: none` без замены. Для полей ввода кольцо сохраняется, дополнительно подсвечивается рамка (`border-color: var(--accent)` + `box-shadow: 0 0 0 3px var(--accent-soft)`).
2. **Тап-таргет** ≥44×44 px.
3. **Контраст** — все значения посчитаны, см. 9.2. Минимум AA (4.5:1) для текста <24px, 3:1 для крупного текста ≥24px и для границ интерактивных элементов.
4. **Клавиатура** — сквозной доступ по всем интерактивным элементам, видимый фокус, `skip-link` к основному контенту.
5. **`prefers-reduced-motion`** — см. раздел 6.
6. **Иконки** — декоративные: `aria-hidden="true"`. Одиночные кнопки: `aria-label` + `role="img"`.
7. **Живые регионы** — тост: `role="status" aria-live="polite"`, ошибка: `role="alert"`.
8. **Не полагаться на цвет** — «верно/неверно» всегда сопровождается иконкой (`check` / `circle-x`) и текстом.

## 10. План миграции

1. **Скопировать** `src/styles/tokens.css` в проект (уже создан), удалить `:root` из `global.css`, импортировать `tokens.css` в `main.jsx` перед `global.css`.
2. **Страницы по очереди** (от самой простой к сложной): `NotFoundPage` → `HomePage` → `WordListsPage` → `StoragePage` → `AddPage` → `LearnPage` → `Header` → `Toast` → `Loader`.
3. **Каждый модуль** заменяет литералы на токены. Ничего не переименовывать в разметке — только значения в CSS.
4. **Кнопки** привести к 4 вариантам из раздела 4; одинаковые по смыслу кнопки на разных страницах получают одинаковый класс.
5. **Эмодзи → SVG** по списку из раздела 7.
6. **Переключатель темы** — кнопка в шапке (`sun`/`moon`), состояние в `localStorage` (`lew-theme`), по умолчанию тёмная.
7. **Нижняя навигация** — новый виджет `BottomNav`, показывается `<768px`, верхняя шапка на мобильном скрывает навигацию.
