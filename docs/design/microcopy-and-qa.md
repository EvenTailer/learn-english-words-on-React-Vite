### B1. Неверный ответ не переводит на следующую карточку

**Шаги воспроизведения**

1. Открыть «Учить» → источник «Все слова», размер 20.
2. Ввести заведомо неверный перевод, нажать «Проверить».
3. Посмотреть на карточку и на полосу «Прогресс сессии».

**Ожидаемое**

Ошибка запоминается, карточка уходит в конец очереди и показывается следующая.
Пользователь двигается по сессии, а не сидит на одном слове.

**Фактическое**

- Карточка не меняется: `currentCardId` остаётся прежним.
- Поле ответа не очищается — в нём остаётся неверный текст,
  повторное нажатие «Проверить» повторяет ту же ошибку.
- Очередь не меняется.
- Счётчик «Отвечено» растёт на каждую ошибку, поэтому после **N** ошибок
  на одной карточке сессия закрывается: `finished = true`, `answered = N`,
  `correct = 0`, а на экране «Отвечено 20 из 20».

**Замер (базовая ревизия, 3 карточки, 20 ошибок)**

```
B1 wrong answer: {"before":"a","after":"a","sameCard":true,"answerField":"wrong",
  "queue":["a","c","b"],"session":{"total":3,"answered":1,"correct":0,"wrong":1,...}}
B2 20 wrong: {"firstCard":"a","currentCardId":null,"finished":true,"queue":[],
  "session":{"total":3,"answered":3,"correct":0,"wrong":3,...}}
```

Пользователь провалил одну карточку три раза подряд — и сессия «из 3 карточек»
закрылась, ни одну карточку кроме первой он не увидел.

**Где**

- `src/features/learn/learnThunks.js:113-133` — ветка ошибки: `return` без смены карточки.
- `src/features/learn/learnThunks.js:111` — `sessionStatAdded({kind:'answered'})` считается и за ошибку.
- `src/features/learn/learnThunks.js:243-248` — `finishIfDone` сравнивает `answered` с `total`.
- `src/features/learn/learnSlice.js:32-34` — `answerChanged` не очищает поле при ошибке.

**Статус**: закрыт в рабочем дереве — `learnThunks.js` получил общий
`moveToNextCard()` (строка 179), который вызывается и из ветки ошибки (строка 131),
и из ветки успеха (строка 168), и из `skipCard` (строка 215).
Замер после правки: `{"before":"a","after":"c","sameCard":false,"answerField":"","queue":["c","b"]}`.

### B2. Слово считается выученным без интервалов

**Шаги воспроизведения**

1. Взять одно слово (например «lion») и ответить на него верно.
2. Сразу же начать новую сессию с тем же источником и снова ответить верно.
3. Повторить 5 раз подряд, не разрывая сессии.

**Ожидаемое**

Слово должно «отдохнуть» на 1 → 3 → 7 → 21 → 60 дней
(`src/features/progress/srs.js:5`). Пятый верный ответ должен случиться
в пятой сессии, с разносом во времени, а не за минуту.

**Фактическое**

Пять сессий подряд, в пределах одной минуты, и слово помечено «выучено»:
статус `mastered`, `learned = 1`.

```
SPACED: [{"session":1,"status":"learning","correct":1,"streak":1,"dueInHours":24},
          {"session":2,...,"correct":2,"streak":2,"dueInHours":72},
          {"session":3,...,"correct":3,"streak":3,"dueInHours":168},
          {"session":4,...,"correct":4,"streak":4,"dueInHours":504},
          {"session":5,"status":"mastered","correct":5,"streak":5,"mastered":true,"learned":1}]
```

**Почему интервал не работает**

После верного ответа слову ставится `dueAt = now + 1 день`
(`src/features/progress/progressSlice.js:87`), но источник «Все слова»
отдаёт и невыученные слова без проверки срока:

```
plan.js:96-100 → return !(entry?.status === 'mastered' && !isDue(entry, now));
```

`dueAt` учитывается только для `status === 'mastered'`.
Замер: сразу после верного ответа `dueAt = +24 ч`,
пул «Все слова» содержит это слово (`poolAll: ["lion","monkey"]`),
а пул «К повторению» — нет (`poolDue: ["lion"]`).

Дополнительно: счётчик `correct` в прогрессе накапливается и **не сбрасывается**
при ошибке (`progressSlice.js:77`), тогда как `streak` сбрасывается
(`progressSlice.js:91`). Ошибка не отодвигает момент «освоения» — только
отодвигает интервал, который всё равно не проверяется.

**Уточнение к жалобе**

Формулировка «5 верных ответов подряд в одной сессии» неточна:
внутри одной сессии карточка обходится один раз (очередь короче сессии),
поэтому 5 верных ответов на одно слово внутри одной сессии получить нельзя.
Реальный дефект шире: **5 верных ответов подряд без интервала**, то есть
5 сессий подряд за пару минут. Именно это и воспроизведено выше.

**Где**

- `src/features/progress/progressSlice.js:5` — `MASTERY_THRESHOLD = 5`.
- `src/features/progress/progressSlice.js:77` — `correct` копится без привязки ко времени.
- `src/features/progress/progressSlice.js:80` — порог освоения.
- `src/features/progress/progressSlice.js:87` — `dueAt` выставляется, но не проверяется.

### B4. Сессия продолжается сама, сменить набор неудобно

**Шаги воспроизведения**

1. Начать тренировку, ответить на пару карточек.
2. Уйти на «Главную» (кнопка «На главную» или нижнее меню).
3. Вернуться в «Учить».

**Ожидаемое**

Открывается экран «Что учим»: пользователь сам выбирает источник, направление
и размер. Прежняя сессия не должна тянуться за собой.

**Фактическое**

- Открывается **та же карточка**, на которой пользователь остановился:
  `currentCardId` не изменился, план сохранился.
- Экран «Что учим» недостижим: он рисуется только при `plan === null`
  (`LearnPage.jsx:171`), а план живёт в `learn`-слайсе.
- Обойти можно только иконкой-списком «Сменить набор слов» в правом верхнем углу
  карточки (`LearnCard.jsx:79-86`) — иконка без подписи, её легко не заметить.
- **Ловушка после конца сессии.** `learnFinished` не чистит `plan`
  (`learnSlice.js:67-74`). После «Сессия завершена» экран «Что учим» недостижим
  вообще: и карточки уже нет (её рисует `SessionSummary`), и вернуться в setup нельзя.
  На экране итогов есть только «Ещё раз» (тот же план) и «На главную».
  Чтобы поменять источник, нужен перезапуск страницы.

**Замер (базовая ревизия)**

```
B4 re-entry: {"currentCardId":"b","planStillSet":true,"sameCard":true}
B4 after session finished: {"finished":true,"planStillSet":true,"currentCardId":null,
  "session":{"total":2,"answered":2,"correct":2,"wrong":0},"summaryShown":true}
```

**Где**

- `src/pages/LearnPage.jsx:171` — setup рисуется только при `plan === null`.
- `src/features/learn/learnSlice.js:11` — план живёт в `learn`-слайсе.
- `src/features/learn/learnSlice.js:67-74` — `learnFinished` не сбрасывает `plan`.
- `src/app/store/index.js:62` — `learn` не персистится: после перезагрузки
  сессия пропадает, а при переходах внутри приложения — остаётся. Поведение
  разное для одного и того же действия, это и сбивает с толку.
- `src/widgets/LearnCard/LearnCard.jsx:79-86` — единственный путь к экрану выбора.

**Статус**: закрыт в рабочем дереве — `LearnPage.jsx` получил
`useEffect(() => () => dispatch(planCleared()), [dispatch])`: при уходе со
страницы план сбрасывается.

**Замечание QA**: побочный эффект — сессия теперь теряется при любом
переходе, даже на «Хранилище» посмотреть слово. Спорное решение.
Мягче: хранить сессию и на экране «Что учим» спрашивать
«Продолжить с прошлого места? — Начать заново», как в Duolingo.

### B6. Дубликат слова: «Слово добавлено», а слова нет

**Шаги воспроизведения**

1. «Хранилище» → «Добавить слово».
2. Ввести слово, которое уже есть (например `Lion`, если в словаре `lion`),
   другой перевод.
3. Нажать «Добавить карточку».

**Ожидаемое**

Либо «Это слово уже в словаре», либо карточка обновляется новым переводом.

**Фактическое**

Пользователь решает, что перевод обновился, — а на экране старый.

**Замер (базовая ревизия)**

**Где**

- `src/pages/AddPage.jsx:236` — тост «Слово добавлено» показывается всегда.

**Статус**: открыт.

**Как лечить**: `cardAdded` должен возвращать признак «уже было» (или
`AddPage` проверяет список до отправки и показывает тост
