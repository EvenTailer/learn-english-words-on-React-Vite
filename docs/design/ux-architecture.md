## 0. Диагноз: что не так сейчас

Пять жалоб сводятся к четырём структурным дефектам, а не к «плохим цветам».

| Жалоба | Корневая причина в коде |
|---|---|
| «Ужасный дизайн — непонятно, куда кликать» | На главной пять конкурирующих точек входа: CTA «Учить слова», вторичные «Хранилище»/«Наборы», кнопка «Начать занятие» внутри кольца цели, плюс дублирующие шапка и нижнее меню. Приоритет не выстроен. (`HomePage.jsx:77-131`) |
| «Захожу в Учить — вижу те же карточки, где остановился» | `learn.plan` живёт в сторе и не сбрасывается при уходе со страницы. `LearnPage` рендерит `LearnSetup` только «внутри» маршрута `/learn` (`LearnPage.jsx:171`), отдельного адреса у экрана выбора нет. Вернувшись на `/learn`, пользователь попадает в ту же сессию. |
| «Нужна кнопка "Выйти", а не только Esc» | Кнопка выхода существует, но это безымянная иконочная кнопка-шеврон (`LearnCard.jsx:70-75`) с текстом только в `aria-label`. Глазами «Выйти» не читается. Из текстовых подсказок есть только «Esc — выйти» (`LearnCard.jsx:223`). Esc выходит мгновенно, без подтверждения и без объяснения, что прогресс сохранится. |
| «Тут должно быть добавить набор — название, блок должен открываться» | Создание своего набора живёт только в модалке с одним полем «Название списка» (`MyLists.jsx:240-262`), внутри вкладки «Мои списки». У набора нет ни описания, ни обложки, ни страницы-карточки — открыть его нельзя, только раскрыть список слов внутри той же вкладки. |
| «Свой список почти невозможно наполнить» | Слово можно положить в свой список только из «Хранилища» (кнопка на карточке слова) или со страницы «Добавить» (`AddPage.jsx:346-360`). В самом окне «Добавить в список» создать список нельзя — только уйти на другую страницу (`AddToListModal.jsx:99-104`). Плюс свой список становится тренируемым лишь после отдельной кнопки «Добавить в словарь» (`MyLists.jsx:225-234`). |

Главный вывод: проблема не в визуале, а в том, что **экрана «выбор блока» не существует как отдельного адресу**, а **набор — не объект с карточкой и содержимым, а запись в сессии**.

## 1. Новая информационная архитектура

### 1.1 Четыре домена

| Домен | Смысл | Что внутри |
|---|---|---|
| **Учить** | Процесс | Выбор занятия → сессия → итоги |
| **Наборы** | Объекты | Готовые наборы + свои наборы, у каждого — карточка и содержимое |
| **Словарь** | Данные | Все слова, фильтры, поиск, удаление |
| **Главная** | Точка входа | Одно следующее действие + прогресс |

Набор (готовый или свой) — центральная сущность: у него есть название, описание, обложка, счётчик слов, прогресс и **прямое действие «Учить»**.

### 1.2 Маршруты

| Маршрут | Экран | Статус |
|---|---|---|
| `/` | Главная | есть |
| `/learn` | Выбор занятия (хаб обучения) | **новый** — вместо текущего смешанного `/learn` |
| `/learn/session` | Сессия (карточка) | **новый маршрут**, вынесен из `/learn` |
| `/learn/summary` | Итоги сессии | **новый маршрут** (сейчас состояние внутри `/learn`) |
| `/sets` | Наборы: готовые + мои | переименование `/wordlists` (+ редирект со старого) |
| `/sets/new` | Создание своего набора | **новый** |
| `/sets/:setId` | Карточка набора | **новый** |
| `/storage` | Словарь | есть |
| `/add` | Добавить слово | есть |
| `*` | 404 | есть |

Ключевое: `/learn` становится **хабом выбора**, а не «экраном, который иногда показывает форму, а иногда карточку». Сессия получает собственный адрес → на неё можно попасть из «Продолжить», из карточки набора, из итогов.

### 1.4 Схема навигации

**Десктоп — шапка (`AppHeader`)**

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ▣ Learn English Words   Главная  Учить  Словарь  Наборы      🔥 7   ☀       │
└──────────────────────────────────────────────────────────────────────────────┘
         ↑ 4 пункта верхнего уровня        серия     тема
```

- Пункта ровно 4: **Главная · Учить · Словарь · Наборы**. Текущие «Хранилище» → «Словарь» (слово «хранилище» читается как склад, а не как список слов).
- «Добавить» уходит из шапки в контекстные точки (кнопка «Добавить слово» на страницах словаря/наборов) — в шапке он конкурирует с навигацией и не является разделом.
- **На время сессии шапка скрывается** (`/learn/session`, `/learn/summary`): фокус-режим, случайный клик мимо карточки не выбрасывает из урока.

**Мобильный — нижнее меню (`BottomNav`)**

```
┌────────────────────────────────────┐
│  ⌂        🧠       ⊕        ▦   ▤   │
│ Главная  Учить   (FAB) Словарь Наборы│
└────────────────────────────────────┘
```

- 4 вкладки + центральная FAB. **FAB меняет смысл**: открывает шторку выбора «Добавить слово» / «Создать набор» — прямой ответ на жалобу «тут должно быть добавить набор».
- На `/learn/session` нижнее меню **скрыто** (иначе тап по «Главной» во время ответа теряет карточку). Выход — только явная кнопка «Выйти» в панели сессии.

**Правило одного уровня:** из сессии нельзя попасть в глубину списка без явного «Выйти». Любой экран третьего уровня (карточка набора, создание набора) открывается из `/sets` и возвращается туда же.

### 1.5 Где «Выйти» и где «Сменить блок» в сессии

```
┌──────────────────────────────────────────────────────────────┐
│ [← Выйти]      Oxford 3000 · A1          [Сменить]  12/20  │
│ ▬▬▬▬▬▬▬▬▬▬▬▬▬░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │  ← прогресс
│                                                              │
│                        S U N F L O W E R                     │
│                    /ˈsʌnˌflaʊə(r)/        🔊                 │
│                                                              │
│  ┌──────────────────────────────────────────────────────┐    │
│  │ Введите перевод…                              🎤     │    │
│  └──────────────────────────────────────────────────────┘    │
│                                                              │
│  [   ✓ Проверить   ]                                        │
│  [ Показать ответ ]  [ Пропустить ]                          │
└──────────────────────────────────────────────────────────────┘
```

- **«Выйти» — текстовая кнопка** слева вверху (`ghost`, высота 44, иконка `arrow-left` + подпись «Выйти»). Подпись обязательна: иконка без подписи не читается.
- По нажатию — **диалог подтверждения**: «Прервать урок? Отвеченные слова сохранятся, к этой сессии можно вернуться.» → «Прервать» / «Продолжить». Двойное подтверждение только для выхода, а не для ответа.
- **«Сменить»** — вторая текстовая кнопка справа: возвращает на `/learn` (хаб выбора) с сохранением прогресса и тостом «Урок сохранён. Выберите другой набор».
- Текущий источник всегда подписан в панели («Oxford 3000 · A1», «Мои слова», «Список "Еда"») — пользователь должен видеть, **что** он сейчас учит, без чтения карточки.
- Esc остаётся как горячая клавиша, но **с тем же диалогом подтверждения**, а не мгновенным выходом.

## 3. Наборы слов: создание, наполнение, попадание в тренировку

### 3.1 Два типа наборов

| | Готовый набор | Свой набор |
|---|---|---|
| Источник | `WORD_SETS` + `wordlists.json` (top250…cefrB2) | локальный, `listsSlice` |
| Как появляется | уже в приложении | пользователь создаёт |
| Наполнение | автоматически, данные из сборки | вручную: добавить слово / выбрать из словаря / вставить список |
| Учится | да, сразу (с однократным импортом в словарь) | да, сразу, без импорта в словарь |
| Метаданные | название, подсказка, размер, уровень | название*, описание, обложка/тема, уровень, дата создания |

### 3.2 Создание своего набора — `/sets/new`

| Шаг | Что видит | Куда кликнуть | Что происходит |
|---|---|---|---|
| N1 | Пункт «Создать набор» (кнопка на `/sets`, FAB-шторка на мобильном, пустое состояние) | «Создать набор» | `/sets/new` |
| N2 | Форма: «Название»* (плейсхолдер «Еда, Путешествия, Работа»), «Описание» (плейсхолдер «Слова для похода»), «Обложка» (чипы-эмодзи: 🍎 🌍 💼 🐾 🎬), «Уровень» (A1/A2/B1/B2/Не важно) | Заполнить | Локальное состояние формы |
| N3 | Кнопка «Создать» активна только при непустом названии | «Создать» | `listCreated` с расширенной моделью → `/sets/:setId` |
| N4 | Карточка набора: пустое состояние «В наборе 0 слов» + три способа наполнить | — | — |

### 3.3 Наполнение набора — три пути, все с карточки набора

| Путь | Шаг | Что видит | Куда кликнуть |
|---|---|---|---|
| **A. Добавить слово** | 1 | Форма прямо на карточке набора: EN, RU, опционально картинка | «Добавить слово» → заполнить → «Добавить» |
| | 2 | Слово появилось в списке, счётчик «1 слово», тост | — |
| **B. Выбрать из словаря** | 1 | Модальное окно: поиск + сетка карточек словаря с чекбоксами | «Выбрать из словаря» → отметить 5 слов → «Добавить (5)» |
| | 2 | Слова добавлены, счётчик обновился | — |
| **C. Вставить список** | 1 | Модальное окно: textarea, формат `english — russian` по строке | «Вставить список» → вставить → «Импортировать (24)» |
| | 2 | Разбор по строкам, предпросмотр количества, ошибки формата подсвечены | «Импортировать» |

**Из словаря — дополнительный вход:** карточка слова в `/storage` → кнопка «в список» → модальное окно «Добавить в набор» со списком наборов и **кнопкой «+ Создать набор» прямо в модалке** (закрывает жалобу «невозможно наполнить»). Созданный набор сразу открывается, выбранное слово попадает в него.

**Из «Добавить слово»:** выпадающий список «Добавить в набор» + пункт «+ Создать новый набор» (создаёт и кладёт слово в него).

### 3.4 Как набор попадает в тренировку

| Путь | Что видит | Куда кликнуть | Что происходит |
|---|---|---|---|
| Из карточки набора | Кнопка «Учить этот набор» | клик | `plan = { source: 'set'|'list', setKey/listId }` → `/learn/session`. Слова берутся **из самого набора**, импорт в общий словарь не требуется |
| С хаба обучения | Сетка наборов с живыми счётчиками | «Учить» | То же |
| Из главной | Блок «Мои наборы» с мини-прогрессом | «Продолжить» | То же |

**Готовый набор:** одна кнопка «Учить» — набор при этом однократно материализуется в словарь (карточки с `sets: [key]`), иначе `selectPool` по `source: 'set'` ничего не найдёт. Тост «Набор добавлен в словарь — 250 слов» делает этот побочный эффект видимым.

**Свой набор:** тренируется напрямую. Кнопка «Добавить в словарь» (`MyLists.jsx:225-234`) в новой модели — вторая по значимости, а не обязательный шлюз: слова набора живут в наборе, общий словарь пополняется по желанию.

**Технические следствия для реализации** (не входят в этот документ, но обязательны к исполнению):
- `lists.items[].words` уже хранит `{ englishWord, russianWord, phonetic, definition, linkImg }` — достаточно для тренировки; `plan.source = 'list'` умеет отбирать по `listWords` (`plan.js:88-89`).
- Модель набора нужно расширить полями `description`, `cover`, `level` и полем `origin: 'builtin' | 'custom'` — иначе готовые и свои наборы нельзя показать в одной сетке.
- `selectPool` для `source: 'list'` ищет слова **в общем словаре** по ключу. Для тренировки своего набора без импорта нужен отдельный источник `source: 'custom'`/`'set'` с `word`-объектами из набора — иначе слово, добавленное только в набор, в тренировку не попадёт.

## 4. Что должно быть видно на главной

Порядок блоков сверху вниз — это и есть ответ на «непонятно, куда кликать»: **один главный призыв, потом цифры, потом варианты, потом контент.**

| № | Блок | Содержимое | Зачем |
|---|---|---|---|
| 1 | **«Следующее действие»** (одна большая карточка) | Если есть пауза: «Продолжить · Oxford 3000 · 12/20» + кнопка «Продолжить». Если нет: «Начать занятие · 20 слов · ~8 минут» + кнопка «Начать» + подпись-ссылка «Выбрать другой набор» | Единственная главная кнопка приложения. Никаких двух одинаковых «Учить» на одном экране |
| 2 | **Метрики** (3 плитки) | Изучено · Всего слов · Серия дней | Контекст без кнопок — они не кликабельны и не должны выглядеть такими |
| 3 | **Цель дня** (кольцо + подпись) | «12 из 20 слов сегодня», кольцо; под ним одна вторичная кнопка «Начать занятие» → `/learn` | Прогресс по цели; не дублирует блок 1, ведёт в хаб |
| 4 | **Быстрые источники** | «К повторению — 7», «Только ошибки — 3», «Новые — 42», «Все — 248» — каждая строка кликабельна и **стартует сессию сразу** | Снимает необходимость открывать форму выбора ради простого «давай повторим ошибки» |
| 5 | **Мои наборы** | Карточки своих наборов: обложка, название, «12 слов · 3 изучено», кнопки «Учить» / «Открыть»; кнопка «Создать набор» | Прямой путь к жалобе №4 и №5 |
| 6 | **Поток слов** | Не первые 12 слов словаря подряд, а **слова к повторению сегодня** (до 12) со статусом new/learning/mastered | Сейчас поток — это случайные 12 слов из словаря без смысла |
| 7 | **Настройки** | Убрать из потока на главной. Перенести в диалог «Настройки» из шапки (тема, направление, дневная цель) | Направление и цель дублируются в `LearnSetup`; два места для одной настройки — источник путаницы |

**Пустая главная** (словарь пуст): вместо блоков 2–6 — одно пустое состояние: «Словарь пуст. Возьмите готовый набор — 250 слов за один клик» + две кнопки «Взять набор» и «Добавить слово».

## 7. Что НЕ меняем

- Модель данных слов (`cards`), прогресса (`progress`), статистики (`stats`) — рабочая и покрыта тестами.
- Дизайн-система: палитра индиго + мята, шкала поверхностей, типографика, 4 варианта кнопки — всё это применяется и в новых экранах, менять палитру не нужно.
- Механику ответа: `checkAnswer` / `revealAnswer` / `skipCard`, нормализацию ответов, SRS-расписание, голосовой ввод, озвучку.
- Набор готовых наборов и их источники данных.
